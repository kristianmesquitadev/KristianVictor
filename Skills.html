PORTFOLIO PROFISSIONAL

Habilidades.

"Dominando as principais ferramentas do mercado para transformar ideias em código limpo, interfaces fluidas e sistemas eficientes."

HTML5

Desenvolvi uma boa base em HTML5 de forma autodidata através de cursos e fóruns online, focando no uso correto de tags semânticas e acessibilidade. Utilizo esses conceitos estruturais para construir páginas bem organizadas e otimizadas.

CSS3

Após dominar a estrutura, foquei no CSS3 para dar vida e estilo às páginas. Aprendi a trabalhar com paletas de cores, alinhamentos complexos e layouts totalmente responsivos, procurando sempre aplicar efeitos e animações modernas.

JavaScript

Dominei os fundamentos essenciais como variáveis, estruturas condicionais, loops e manipulação do DOM. Atualmente, estou avançando nos estudos e entrando agora na parte de consumo e integração de APIs e funções assíncronas.

React.js

Com a base da linguagem consolidada, avancei para o React.js para aprender a construir interfaces modernas. O meu foco tem sido entender o ciclo de vida dos componentes, a criação de elementos modulares reaproveitáveis e a gestão de estados.

React Native

Expandindo os horizontes para o mercado mobile, aprendi os fundamentos do React Native. Compreendi como funciona a estrutura de uma aplicação híbrida e como reaproveitar o conhecimento de web para gerar apps para Android e iOS.

C#

Tive os meus primeiros contatos com o C# para entender como funciona a sintaxe de uma linguagem fortemente tipada e os conceitos mais básicos de lógica voltada para o back-end.

Figma

Utilizo o Figma como minha ferramenta principal para desenhar as interfaces antes de começar a codar. Desenvolvi habilidades em criar wireframes, protótipos interativos e definir a identidade visual (UI/UX) dos meus projetos.
